# Conformance vectors

Every Honeypot implementation must reproduce these exactly.

| File | Covers | Generated by |
|---|---|---|
| `core.json` | main key split, boxes (plaintext, nonce, key input, open key, commitment, ciphertext, id, signature, wire), properties, a rewrite, blueprints, draws (commitment, ticket, item, box), capped draws with a sold out item, the roll with its retry, and boxes and keys that must be rejected | `go test . -update` in `go/` |

The main key and each box's entropy are fixed, and signatures use the deterministic
variant of ML-DSA-65 (FIPS 204), so every byte is reproducible.
